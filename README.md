# Minha Extensão Chrome

Extensão desenvolvida como parte de uma atividade prática para aprender e aplicar conceitos de desenvolvimento de extensões para o Google Chrome.

## Sobre o projeto

O projeto consiste em uma extensão para o navegador Chrome, desenvolvida durante uma atividade de estudo.

A extensão utiliza JavaScript para implementar sua lógica e possui uma interface própria através de HTML. O projeto também trabalha com arquivos específicos de uma extensão do Chrome, como `manifest.json`, `background.js` e `content.js`.

## Tecnologias utilizadas

* JavaScript
* HTML
* Chrome Extensions

## Estrutura

O projeto possui arquivos responsáveis pela interface da extensão, execução de scripts em segundo plano e interação com as páginas do navegador.
